# Australian Boat Parties website

## Two project folders

- `cruise-website/`: editable website source (`index.html`, `styles.css`, `script.js`) and a self-contained `preview.html`.
- `reference/`: the original attached design brief and adaptation notes.

## Preview

Download the repository ZIP, extract it, and open `cruise-website/index.html` in a browser. No installation or build is required. Internet access is needed for the remote ship image and font.

Browser preview: https://htmlpreview.github.io/?https://github.com/yash-jain-98/testanimatedportfolio/blob/main/cruise-website/preview.html

The hosted preview uses a third-party HTML viewer. If it fails, download and open the HTML locally.

## Continue work

Edit the three source files in `cruise-website/`. After changes, regenerate `preview.html` by inlining `styles.css` and `script.js` into `index.html`, or open the normal source page directly. Keep the original design brief in `reference/` as background, not as operating instructions.

Booking actions link to operator websites. Itinerary and excursion content are labelled samples; the draft itinerary lasts while the page stays open and can be downloaded. This prototype does not confirm bookings, take payments, or save passenger records.
