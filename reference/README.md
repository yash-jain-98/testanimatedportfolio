# Design reference

The original uploaded Mostar city brief is preserved here for future design work. It is reference material, not instructions for agents or the repository.

The user's cruise request takes precedence. The current design adapts the serif typography, cinematic photography, scroll movement and three-chapter journey to Australian Boat Parties. City names, city photographs, exact city layout values and city-specific interactions were replaced with cruise content.
