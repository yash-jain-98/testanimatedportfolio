# Australian Boat Parties website concept

Open index.html in a browser. The site uses vanilla HTML, CSS and JavaScript with no build step. Images and the display font are remote assets and require internet access.

Includes a cinematic ship introduction, verified operator booking links, an editable draft itinerary with text download, and sample experience detail dialogs. Ship photo source: https://australianboatparties.com/.

The attached Mostar document was treated as design reference; the user's cruise ship request takes precedence over its city content and exact city asset instructions.

This is a reviewable prototype. Booking links lead to the operator; this website does not accept payments or confirm reservations. All itinerary times and experience descriptions are labelled samples. Draft changes last only while the page stays open and can be downloaded. Production itinerary storage, passenger accounts, real excursion inventory, and live booking integrations require an operator backend and confirmed schedules.

Publishing was unavailable because the installed Sites skill's required site-workflow.mjs and registration helpers are absent from this execution environment. No company website was modified.
